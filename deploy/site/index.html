Built in together

      
The best parts of three tools. None of the setup.

Install

      
Up and running in a minute.

      
Everything lmux needs is inside the app. There's nothing else to set up.

      

        
01
Download
Get lmux.dmg and open it.

        
02
Drag to Applications
Drag lmux onto the Applications folder, then open it from there.

        
03
Allow folder access
If macOS asks whether lmux may use a folder like Documents, click Allow. It asks once.

      

      

        If macOS says it can't check lmux for malicious software, open System Settings › Privacy & Security,
        scroll down and click Open Anyway. This step goes away once the build is notarized by Apple.
      


      

        

          Add a server
          
Right-click the sidebar.

          
Choose Add Remote Host… and enter an SSH address like me@my-server. lmux installs itself there over SSH.
