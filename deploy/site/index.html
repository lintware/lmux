lmux

Terminal and browser workspaces that keep running on your Mac and your servers.

Download for Mac
Version @VERSION@ · macOS 12 or later · Apple silicon

Install

  1. Open lmux.dmg and drag lmux to Applications.
  2. Install tmux, which keeps your terminals running: brew install tmux
  3. Open lmux from Applications. If macOS asks to access a folder like Documents, click Allow. It asks once.
If macOS says it can't check lmux for malicious software, open System Settings › Privacy & Security, scroll down and click Open Anyway. This step goes away once the build is notarized by Apple.

Use it with a server

Right-click the sidebar and pick Add Remote Host…, then enter an SSH target such as me@my-server. lmux installs itself on that host over SSH. The host needs tmux, a Rust toolchain (curl https://sh.rustup.rs -sSf | sh), and on Linux loginctl enable-linger $USER so terminals outlive logout.
